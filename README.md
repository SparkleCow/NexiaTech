# Nexiatech

## What is NexiaTech ? 

Nexiatech is a single-page marketing site and software engineering/infrastructure firm portal built with TanStack Start (powered by React 19, Vite, and Tailwind v4) and synchronized with the Lovable platform

This page documents the local development environment, dependency management, build configuration, and code quality tooling for NexiaTech. The codebase relies on Bun as the package manager and runtime ecosystem, Vite bundled via @lovable.dev/vite-tanstack-config for hot-reloading and bundling, TanStack Start for full-stack routing and server-side rendering (SSR), TypeScript for strict type safety, and ESLint/Prettier for code formatting.
